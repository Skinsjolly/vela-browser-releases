## Linux quick start

```sh
chmod +x Vela-Browser-1.0.0-linux-x86_64.AppImage
./Vela-Browser-1.0.0-linux-x86_64.AppImage
```

The tar.gz is portable: extract it and run the `vela-browser` executable.

## Windows

The Windows build is an unsigned portable ZIP. Extract it and run `Vela Browser.exe`. SmartScreen may warn because the build is not code-signed; verify the checksum before running.
